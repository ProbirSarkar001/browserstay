## How to Spot a Private Tool

Quick checklist:

1. **No upload progress bar** when you add files
2. **Privacy policy says "processed locally" or "in your browser"**
3. **Open source** — code is public and auditable
4. **Works after disconnecting WiFi** (after initial page load)
5. **No account required** for basic tasks

If you see an upload step, your file left your device. Period.

## When Upload-Based Tools Are OK

Private tools aren't always necessary. Upload-based tools are fine when:

- The file is public (marketing brochure, published report)
- You need features only servers provide (OCR, e-sign, exotic formats)
- You're processing one non-sensitive file and don't want to think about it

For everything else — taxes, contracts, medical records, personal photos, WiFi passwords — use tools that keep data local.
