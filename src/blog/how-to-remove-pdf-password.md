You saved a PDF years ago and protected it with a password. Now you need to open it on a new device — and you remember the password, but the tool you're using won't let you remove the lock.

Or you received a password-protected PDF from a colleague, they gave you the password, and you want an unencrypted copy for easier access.

Here's how PDF unlocking works — and why you should never upload a password-protected document to a random website.

## What "Unlocking" Means

Removing a PDF password means decrypting the file contents and saving a new PDF without encryption. You need the **correct open password** — this isn't cracking or bypassing security. It's using the key you already have to create an unencrypted copy.

If you don't know the password, no legitimate tool can help. That's the point of encryption.

## When Unlocking Is Appropriate

- **Your own file** — you set the password and want an unencrypted copy
- **You have permission** — someone shared the password with you explicitly
- **Removing restrictions** — some PDFs have owner-password restrictions (no printing, no copying) that you want lifted on a document you're authorized to use

Unlocking someone else's protected document without permission is not okay.

## The Privacy Problem with Online Unlock Tools

Unlocking requires your password. If you upload a protected PDF to a website and type the password into their form, you're giving them:

- The encrypted file
- The decryption password
- The ability to read the entire document

Many "unlock PDF" sites log both. For sensitive documents, that's unacceptable.

## How to Unlock Locally

1. **Open the protected PDF** in a browser-based tool that runs locally
2. **Enter the password** — it stays in your browser, never sent to a server
3. **Decrypt and download** — the tool creates an unencrypted copy on your device
4. **Save the new file** — the original encrypted PDF remains unchanged

Your password and document contents never leave your computer.

## After Unlocking

- Store the unencrypted copy securely — it's no longer protected by a password
- Delete unencrypted copies when you no longer need them
- Re-encrypt if you need to share again
