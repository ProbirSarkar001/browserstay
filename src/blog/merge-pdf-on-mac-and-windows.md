You have multiple PDFs that need to become one. The method you choose affects speed, privacy, and whether you need to install anything.

Here's every common approach — and which ones keep your files off the internet.

## Mac: Preview (Built-In)

**How:** Open the first PDF in Preview. Show the sidebar (View → Thumbnails). Drag additional PDFs from Finder into the sidebar. Reorder thumbnails. File → Export as PDF.

**Pros:** Free, built-in, no upload, works offline
**Cons:** Mac only; large merges can be slow; limited control over page-level merging from multi-page sources

**Privacy:** Excellent — everything stays on your Mac.

## Windows: Limited Built-In Options

**Microsoft Edge** can view PDFs but doesn't merge them natively. Windows doesn't include a free PDF merger like Mac's Preview.

**Options for Windows:**
- Install a desktop app (PDFsam, Adobe Acrobat, PDF-XChange)
- Use a browser-based tool that processes locally
- Use online upload tools (not recommended for sensitive files)

## Adobe Acrobat (Mac and Windows)

**How:** Tools → Combine Files. Add PDFs, arrange, combine.

**Pros:** Full-featured, reliable, industry standard
**Cons:** Paid subscription for full features; installation required

**Privacy:** Excellent — local processing.

## Browser-Based Tools (Mac, Windows, Linux, Chromebook)

**How:** Open a merge tool in your browser. Add PDFs (they load into memory, not uploaded). Reorder, merge, download.

**Pros:** No install, works on any OS, free options available, privacy-preserving if truly client-side
**Cons:** Requires initial page load; very large files may stress browser memory

**Privacy:** Excellent if the tool runs locally — verify it's not an upload-based service.

## Online Upload Tools (Avoid for Sensitive Files)

**How:** Upload PDFs to a website, wait for processing, download result.

**Pros:** No install, works everywhere
**Cons:** Your files go to a server; watermarks and paywalls common; privacy policies vary

**Privacy:** Poor — assume the service has seen your files.

## Comparison Table

| Method | Cost | Install | Privacy | Best for |
|--------|------|---------|---------|----------|
| Mac Preview | Free | No | Excellent | Mac users, quick merges |
| Adobe Acrobat | Paid | Yes | Excellent | Power users, complex jobs |
| Browser (local) | Free | No | Excellent | Any OS, no install |
| Online upload | Free* | No | Poor | Non-sensitive files only |

*Often with watermarks or limits

## Our Recommendation

- **Mac users:** Preview is great for simple merges
- **Windows users:** Browser-based local merge or a trusted desktop app
- **Sensitive documents:** Never use upload-based tools
- **No install needed:** Browser-based tools that process locally
