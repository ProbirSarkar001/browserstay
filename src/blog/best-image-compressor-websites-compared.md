You need to shrink a photo before emailing it or uploading it to a website. Search "compress image online" and you'll get dozens of options — all promising smaller files without visible quality loss.

The real differences are in privacy, batch limits, format support, and whether "free" comes with a catch.

## What We Compared

- **Processing** — server upload vs browser-local
- **Formats** — JPEG, PNG, WebP, AVIF, HEIC
- **Batch support** — one image or hundreds
- **Quality control** — adjustable compression level
- **Free limits** — file size, daily tasks, watermarks
- **Privacy** — do your images leave your device?

## Server-Upload Compressors

**TinyPNG, Compressor.io, iLoveIMG, ShortPixel, Kraken.io** dominate search results.

**Strengths:**
- Polished interfaces refined over years
- TinyPNG's automatic optimization is genuinely good for PNG/WebP
- ShortPixel and Kraken offer API access for developers
- Handle very large files on powerful servers

**Weaknesses:**
- **Your images are uploaded** — personal photos, screenshots with sensitive data, client work
- **TinyPNG: 20 images per batch** on free tier
- **ShortPixel: 100 images/month** free
- **Compressor.io: one image at a time** — tedious for batches
- Privacy depends on trusting deletion policies

**Best for:** Website assets, public images, marketing photos you don't mind uploading.

## Browser-Based Local Tools

### BrowserStay

Compresses images in your browser with adjustable quality, batch support, and ZIP download.

**Strengths:**
- Files never uploaded
- JPG, PNG, WebP, AVIF, HEIC support
- Quality slider and resize in one workflow
- No daily limits, open source

**Weaknesses:**
- No API for automated pipelines
- Very large batches slower on older devices

**Best for:** Personal photos, client images, screenshots with confidential content.

### Squoosh (by Google)

Runs entirely in the browser — one of the few major browser-local compressors.

**Strengths:**
- Excellent quality comparison slider (before/after)
- Supports many codecs including AVIF
- Fully local, no upload
- Open source

**Weaknesses:**
- **One image at a time** — no batch processing
- No ZIP download for multiple files
- Geared toward developers and designers, not casual users

**Best for:** Comparing compression settings on a single image.

## How to Choose

| Situation | Best choice |
|-----------|-------------|
| Personal photos, privacy matters | BrowserStay |
| Single image, want before/after preview | Squoosh |
| Batch of website PNGs, OK with upload | TinyPNG |
| Developer API for automated compression | ShortPixel or Kraken |
| Quick one-off JPG, don't care about upload | Compressor.io |
| HEIC iPhone photos | BrowserStay (local HEIC support) |

## Quality vs Size: What to Expect

Most tools can reduce a photo by 50–80% with minimal visible loss. The sweet spot:

- **Quality 80–85** — great for web and email
- **Quality 70–80** — smaller files, still good for most uses
- **Below 70** — visible artifacts; only for thumbnails

Resize before compressing for the biggest win. A 4000px photo displayed at 800px wastes pixels whether you compress or not.
