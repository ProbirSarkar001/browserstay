## Server-Upload Converters

**CloudConvert, Convertio, iLoveIMG, Zamzar** support the widest range of formats because server-side processing can use any codec.

**Strengths:**
- CloudConvert supports 200+ formats
- Convertio handles obscure formats (TIFF, BMP, RAW in some cases)
- No install required
- API access on paid tiers

**Weaknesses:**
- **Files uploaded before conversion**
- **CloudConvert: 25 free conversions/day**
- **Convertio: 10 files/day** on free tier
- **Zamzar: 2 files/day** — very restrictive
- Personal photos and client assets sit on third-party servers

**Best for:** Obscure format conversions, one-off non-sensitive files.

## Browser-Based Converters

### BrowserStay

Converts between JPG, PNG, WebP, AVIF, and HEIC locally.

**Strengths:**
- Never uploads files
- Batch convert with ZIP download
- Dedicated SEO pages per conversion pair ([HEIC to JPEG](/image-converter/heic-to-jpeg), [PNG to WebP](/image-converter/png-to-webp), etc.)
- Quality slider, open source

**Weaknesses:**
- Fewer exotic formats (no TIFF, BMP, RAW)
- Browser memory limits very large batches

**Best for:** Common web formats, iPhone HEIC photos, batch conversion of personal images.

### Squoosh

Google's browser-based compressor/converter.

**Strengths:**
- Fully local, excellent codec support including AVIF
- Side-by-side quality comparison

**Weaknesses:**
- One image at a time
- No HEIC input support
- No batch or ZIP

**Best for:** Single-image format experiments.

## Desktop: XnConvert

Free, cross-platform batch converter supporting 500+ formats.

**Strengths:** Offline, unlimited batch, every format imaginable
**Weaknesses:** Installation required, utilitarian interface

**Best for:** Power users who convert frequently and need obscure formats.
